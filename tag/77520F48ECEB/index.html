Lemma 9.4.10

From Singularities in global pluripotential theory · Lemma 9.4.10

Lemma 9.4.10. Let $\Gamma ,\Gamma '\in \mathrm{TC}(X,\theta )_{>0}$. Then for any $\tau <\Gamma _{\max }\lor \Gamma '_{\max }$, we have

\[ \operatorname{CE}\left( \rho \mapsto \Gamma _{\rho }\lor \Gamma '_{\rho } \right)_{\tau }\in \mathrm{PSH}(X,\theta ), \]

and $\Gamma \lor \Gamma '\in \mathrm{TC}(X,\theta )_{>0}$.

This potential is $\mathcal{I}$-good if $\Gamma ,\Gamma '\in \mathrm{PSH}^{\mathrm{NA}}(X,\theta )_{>0}$.

In particular, (9.80) in definition 9.4.9 makes sense.

Proof. To simplify the notation, we write

\[ \psi _{\tau }=\operatorname{CE}\left( \rho \mapsto \Gamma _{\rho }\lor \Gamma '_{\rho } \right)_{\tau } \]

for all $\tau \in \mathbb {R}$. Thanks to proposition A.2.10, for any fixed $x\in X$, we have

9.81
\begin{equation} \label{eq:psistartemp1} \psi ^*_ t(x)=\Gamma ^*_ t(x)\lor \Gamma '^*_ t(x) \end{equation}

for all $t>0$ as long as $\Gamma _{\tau }(x)\neq -\infty $ and $\Gamma '_{\tau }(x)\neq -\infty $ for some $\tau \in \mathbb {R}$. Otherwise, assume for instance that $\Gamma _{\tau }(x)=-\infty $ for all $\tau \in \mathbb {R}$; then by definition, $\psi _{\tau }(x)=\Gamma '_{\tau }(x)$ for all $\tau \in \mathbb {R}$. Therefore, $\Gamma ^*_ t(x)=-\infty $ for all $t>0$ and (9.81) continues to hold. The case where $\Gamma '_{\tau }(x)=-\infty $ for all $\tau $ is symmetric. Therefore, we have shown that

\[ \psi ^*_ t=\Gamma ^*_ t\lor \Gamma '^*_ t\in \mathrm{PSH}(X,\theta ). \]

It follows from proposition 4.1.9 that $(\psi ^*_ t)_{t\in [a,b]}$ is a subgeodesic for any $0< a<b$.

Next we observe that $\psi _{\bullet }$ is closed by definition. So it follows from proposition A.2.10 and proposition 1.2.11 that

\[ \psi _{\tau }=(\psi ^*_{\bullet })^*_{\tau }\in \mathrm{PSH}(X,\theta )\cup \{ -\infty \} . \]

Due to proposition 9.1.9 and proposition A.1.11, there is a pluripolar set $Z\subseteq X$ such that for $x\in X\setminus Z$, we have

\[ \begin{split} \psi _{\tau }(x)=\sup \left\{ \lambda \Gamma _{\rho }(x)+(1-\lambda )\Gamma '_{\rho '}(x): \lambda \in (0,1),\rho ,\rho '\in \mathbb {R},\lambda \rho +(1-\lambda )\rho '=\tau \right\} \end{split} \]

for all $\tau <\Gamma _{\max }\lor \Gamma '_{\max }$. It follows from proposition 1.2.6 that

9.83
\begin{equation} \label{eq:psitausupslineartemp} \begin{split} \psi _{\tau }=\operatorname *{sup}_{}{}\! {}^{*}\left\{ \lambda \Gamma _{\rho }+(1-\lambda )\Gamma '_{\rho '}: \lambda \in (0,1),\rho ,\rho '\in \mathbb {R},\lambda \rho +(1-\lambda )\rho '=\tau \right\} \end{split} \end{equation}

for all $\tau <\Gamma _{\max }\lor \Gamma '_{\max }$.

We now check that $\Gamma \lor \Gamma '$ is a test curve. The function $\rho \mapsto \Gamma _\rho \lor \Gamma '_\rho $ is decreasing, hence its upper concave envelope $\psi _\bullet $ is decreasing. The monotonicity of the $P$-envelope proposition 3.1.24 3 gives the decreasingness of $\Gamma \lor \Gamma '$. Since $\psi _\bullet $ is concave by construction, proposition 3.1.24 gives the concavity of $\Gamma \lor \Gamma '$.

Fix $\tau <\Gamma _{\max }\lor \Gamma '_{\max }$. Then either $\tau <\Gamma _{\max }$ or $\tau <\Gamma '_{\max }$. Since $\psi _\bullet $ is a concave majorant of $\rho \mapsto \Gamma _\rho \lor \Gamma '_\rho $, we have

\[ \psi _\tau \geq \Gamma _\tau \quad \text{if } \tau <\Gamma _{\max }, \qquad \psi _\tau \geq \Gamma '_\tau \quad \text{if } \tau <\Gamma '_{\max }. \]

Together with the fact that $\psi _\tau \in \mathrm{PSH}(X,\theta )\cup \{ -\infty \} $, these inequalities show that $\psi _\tau \in \mathrm{PSH}(X,\theta )$. It follows from 9.1.3 and the monotonicity theorem theorem 2.4.8 that $\psi _\tau \in \mathrm{PSH}(X,\theta )_{>0}$. By corollary 3.1.12,

\[ (\Gamma \lor \Gamma ')_\tau =P_\theta [\psi _\tau ] \]

is a model potential. Finally, $(\Gamma \lor \Gamma ')_{-\infty }\in \mathrm{PSH}(X,\theta )$ by proposition 1.2.2; since it dominates $(\Gamma \lor \Gamma ')_\tau $ for any $\tau <\Gamma _{\max }\lor \Gamma '_{\max }$, it has positive mass by another application of the monotonicity theorem theorem 2.4.8. Thus $\Gamma \lor \Gamma '\in \mathrm{TC}(X,\theta )_{>0}$.

It follows from (9.83) that $\psi _{\tau }$ is $\mathcal{I}$-good if $\Gamma ,\Gamma '\in \mathrm{PSH}^{\mathrm{NA}}(X,\theta )_{>0}$, thanks to proposition 7.2.1 and proposition 7.2.3; the family in the upper envelope is bounded above by $0$. Since $(\Gamma \lor \Gamma ')_\tau =P_\theta [\psi _\tau ]$, we conclude that $\Gamma \lor \Gamma '$ is $\mathcal{I}$-model in this case. $\square$
