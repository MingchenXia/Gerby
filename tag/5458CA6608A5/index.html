Pluripolar sets

One local pluripolarity definition. The source versions also introduce different related terminology, including global pluripolarity, quasi-everywhere statements, and co-pluripolar sets.

From Foundations of pluripotential theory · Definition 10.1.1

Definition 10.1.1. Let $X$ be a complex manifold. A subset $E\subset X$ is pluripolar, or locally pluripolar, if every point of $X$ has a connected coordinate neighborhood $U$ carrying a function $V\in \mathrm{PSH}(U)$ with $E\cap U\subset \{ V=-\infty \} $. If $X$ is connected, a subset $E\subset X$ is globally pluripolar in $X$ if there is a single $V\in \mathrm{PSH}(X)$ with $E\subset \{ V=-\infty \} $. A property holds quasi-everywhere if it holds outside a pluripolar set.

From Singularities in global pluripotential theory · Definition 1.1.15
Read this source version and its proof notes

Definition 1.1.15. A subset $E\subseteq X$ is pluripolar if for any $x\in X$, there is an open neighborhood $U$ of $x$ in $X$ and a function $\psi \in \mathrm{PSH}(U)$ such that

\[ \psi |_{E\cap U}\equiv -\infty . \]

A subset $E\subseteq X$ is non-pluripolar if $E$ is not pluripolar.

A subset $F\subseteq X$ is co-pluripolar if $X\setminus F$ is pluripolar.
