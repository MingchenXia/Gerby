Global potentials and positive cohomology classes · Tag B72607AB8B41

Divisorial logarithmic residual

From Foundations of pluripotential theory · Corollary 14.3.9

Corollary 14.3.9. Let $\varphi \in \mathrm{PSH}(X,\theta )$, let $D_1,\ldots ,D_ N$ be distinct prime divisors and $a_1,\ldots ,a_ N>0$ real numbers, and put $D=\sum _ ia_ iD_ i$. Suppose that $\varphi $ has logarithmic singularities along $D$ with bounded remainder: near each point, $\varphi =\sum _ ia_ i\log |s_ i|^2+v$ with $v$ bounded, where $s_ i$ is a local equation of $D_ i$ (lemma A.2.16), and $s_ i=1$ if the point does not lie on $D_ i$. Then $\{ \theta \} -\{ D\} $ is nef, where $\{ D\} =\sum _ ia_ i\{ [D_ i]\} $. If $\theta +\mathrm{dd}^{\mathrm{c}}\varphi $ is a Kähler current, then $\{ \theta \} -\{ D\} $ is Kähler.

Proof. Near a point, let $h$ be smooth with $\mathrm{dd}^{\mathrm{c}}h=\theta $. Off the support of $D$ the function $v+h=(\varphi +h)-\sum _ ia_ i\log |s_ i|^2$ is plurisubharmonic, since $\log |s_ i|^2$ is pluriharmonic there, and it is bounded above. On a connected coordinate neighborhood of the point, the support of $D$ lies in the zero set of the holomorphic function $\prod _ is_ i\not\equiv 0$, so theorem 8.4.1 extends $v+h$ to a plurisubharmonic function $\widetilde v$. The values of $\widetilde v$ on the support of $D$ are upper limits of values of $v+h$, so $\widetilde v$ is bounded, and $\widetilde v=v+h$ outside the null set $\operatorname{Supp}D$. Since $\mathrm{dd}^{\mathrm{c}}\log |s_ i|^2=[D_ i]$ (lemma A.2.16), the current $T=\theta +\mathrm{dd}^{\mathrm{c}}\varphi $ satisfies $T-[D]=\mathrm{dd}^{\mathrm{c}}\widetilde v\geq 0$ near the point, where $[D]=\sum _ ia_ i[D_ i]$. Thus $T-[D]$ is a positive current in $\{ \theta \} -\{ D\} $ with locally bounded potentials. If $T\geq \delta \omega $, apply the same argument to $T-\delta \omega $, whose potential has the same logarithmic singularities; then $T-[D]\geq \delta \omega $. In both cases proposition 14.3.5 gives the assertion. $\square$
