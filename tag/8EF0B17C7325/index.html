Pluripolar sets and the plurifine topology · Tag 8EF0B17C7325

Psh pluripolar discrepancy

From Foundations of pluripotential theory · Corollary 10.2.2

Corollary 10.2.2. Let $X$ be a complex manifold of dimension $n$.

  1. If $(u_ i)_{i\in I}$ is a nonempty family in $\mathrm{PSH}(X)$ that is locally uniformly bounded above and $F=\sup _ iu_ i$, then the set $\{ F<F^*\} $ is pluripolar.

  2. If $(u_ j)$ is an increasing sequence in $\mathrm{PSH}(X)$ that is locally uniformly bounded above, then $\lim _ ju_ j=(\sup _ ju_ j)^*$ quasi-everywhere; here $(\sup _ ju_ j)^*$ is plurisubharmonic by theorem 8.3.2.

  3. If $u_1,\ldots ,u_ q$, $1\le q\le n$, are locally bounded plurisubharmonic functions on $X$, then the product $\mathrm{dd}^{\mathrm{c}}u_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}u_ q$ does not charge any Borel pluripolar set. More precisely, in every chart, every pluripolar set has outer measure zero for the trace measure of this product and for the total variations of its coefficient measures.

Proof. (1) Let $x\in X$, and let $B$ be a coordinate ball around $x$, identified with an open ball in $\mathbb C^ n$. On $B$ the regularization $F^*$ is the regularization of $F|_ B$, so by corollary 9.5.2 the set $L\cap \{ F<F^*\} $ has outer capacity zero in $B$ for every compact set $L\subset B$. Exhausting $B$ by countably many compact sets, we obtain $\operatorname {Cap}_ B^*(B\cap \{ F<F^*\} )=0$. By theorem 10.1.4, $B\cap \{ F<F^*\} $ lies in the pole set of a plurisubharmonic function on $B$. Hence $\{ F<F^*\} $ is pluripolar.

(2) For an increasing sequence, $\lim _ ju_ j=\sup _ ju_ j$, so this is the special case of (1) for the family $(u_ j)$.

(3) Let $E$ be pluripolar, and work in a chart, identified with an open set $\Omega \subset \mathbb C^ n$. Let $B'\Subset B\Subset \Omega $ be concentric open balls. The set $E\cap B$ is pluripolar in $B$, so $\operatorname {Cap}_ B^*(E\cap B)=0$ by theorem 10.1.4.

Let $\mu $ be the trace measure of the product, or the total variation of one of its coefficient measures. The restrictions of $u_1,\ldots ,u_ q$ to $B$ form a family that is uniformly bounded on each compact subset of $B$, since $\overline B\subset \Omega $ is compact; so lemma 9.4.7(1), applied to this family and the compact set $\overline{B'}$, gives a constant $C$ with $\mu (A)\le C\operatorname {Cap}_ B(A)$ for every Borel set $A\subset \overline{B'}$. Given $\varepsilon >0$, choose an open set $G\supset E\cap B$ with $\operatorname {Cap}_ B(G)<\varepsilon $; then the outer measure of $E\cap B'$ satisfies $\mu ^*(E\cap B')\le \mu (G\cap B')\le C\operatorname {Cap}_ B(G\cap B')\le C\operatorname {Cap}_ B(G)<C\varepsilon $. Hence $\mu ^*(E\cap B')=0$. Since $\Omega $ is covered by countably many such balls $B'$, the set $E\cap \Omega $ has outer measure zero for $\mu $. For a Borel set $E$ this means that the product does not charge $E$. $\square$
