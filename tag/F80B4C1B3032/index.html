Rooftop envelopes

The same rooftop construction in the closed Kähler setting, with different notation. Both source versions retain the convention for an identically minus-infinity input.

From Foundations of pluripotential theory · Definition 16.1.5

Definition 16.1.5. For $u,v\in \mathrm{PSH}(X,\theta )$, the rooftop envelope of $u$ and $v$ is

\[ P_\theta (u,v)=P_\theta (\min \{ u,v\} ). \]

We also put $P_\theta (u,-\infty )=P_\theta (-\infty ,u)=-\infty $ for $u\in \mathrm{PSH}(X,\theta )\cup \{ -\infty \} $.

From Singularities in global pluripotential theory · Definition 3.1.1
Read this source version and its proof notes

Definition 3.1.1. Given $\varphi ,\psi \in \mathrm{PSH}(X,\theta )$, we define their rooftop operator as follows:

3.1
\begin{equation} \label{eq:rooftopdef1} \varphi \land \psi =\sup \left\{ \eta \in \mathrm{PSH}(X,\theta ):\eta \leq \varphi ,\eta \leq \psi \right\} . \end{equation}

For simplicity of notation, we extend the definition to the case where $\varphi $ or $\psi $ is constantly $-\infty $, in which case we simply set

\[ \varphi \land \psi =-\infty . \]
