10.14 Null loci and numerical restricted volumes9CCCA75301B4

9CCCA75301B4

In this section $X$ is Kähler and $\omega $ is a Kähler form. For a closed class $\alpha $ and an irreducible analytic subvariety $V\subset X$ of positive dimension, the intersection number $\int _ V\alpha ^{\dim V}$ is computed by pulling back a smooth closed representative to a resolution of $V$; by Stokes' theorem it does not depend on the representative. For a nef class $\alpha $, the subvarieties on which this number vanishes form the classical null locus

\[ \operatorname {Null}(\alpha ) =\bigcup _{\substack {V\subset X\ \mathrm{irreducible},\ \dim V>0\\ \int _ V\alpha ^{\dim V}=0}}V. \]

For a nef and big class, the classical theorem discussed in section 25.18 gives

\[ E_{\mathrm{nK}}(\alpha )=\operatorname {Null}(\alpha ). \]

The same equality holds on compact manifolds in class $\mathcal C$.

For a pseudoeffective class that is not nef, intersection numbers are replaced by numerical restricted volumes. Let $V\subset X$ be an irreducible compact analytic subvariety of dimension $k>0$, with regular locus $V_{\mathrm{reg}}$. If $V\subset E_{\mathrm{nn}}(\alpha )$, the numerical restricted volume of $\alpha $ along $V$ is defined to be zero. Otherwise, for real $\varepsilon >0$, let $T$ range over the closed currents in $\alpha $ with $T\geq -\varepsilon \omega $ that have analytic singularities with smooth remainder and whose polar set does not contain $V$, and set

49BB745D6E17 10.14.1
\begin{equation} \langle \alpha ^ k\rangle _{X\mid V} =\lim _{\varepsilon \downarrow 0}\ \sup _ T \int _{V_{\mathrm{reg}}} \bigl ((T+\varepsilon \omega )|_{V_{\mathrm{reg}}}\bigr )_{\mathrm{ac}}^ k, \end{equation}

where the subscript $\mathrm{ac}$ denotes the absolutely continuous part of a measure on $V_{\mathrm{reg}}$. Because $T$ has smooth remainder, the integrand is the extension by zero of a smooth measure defined away from an analytic subset of $V$.

The numerical null locus of $\alpha $ is the union of the positive-dimensional irreducible subvarieties on which (10.14.1) vanishes. The trace theory of [Chapter 8, SGPT] expresses these restricted volumes as masses of trace currents on $V$; this is why singularity types and restrictions of multiplier ideals enter into the identification of this locus. Such a trace need not equal the pointwise restriction of a singular potential; see section 20.3.
