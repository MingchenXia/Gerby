Chapter 5 · Plurisubharmonic functions and positive currents · Tag EB9F157B42F2

The higher dimensional case

From Singularities in global pluripotential theory · 1.1.2 The higher dimensional case

We will fix $n\in \mathbb {N}$ and a domain $\Omega $ (a connected open subset) in $\mathbb {C}^ n$.

Definition 1.1.3. When $n\geq 1$, a plurisubharmonic function on $\Omega $ is a function $\varphi \colon \Omega \rightarrow [-\infty ,\infty )$ satisfying the following three conditions:

  1. $\varphi \not\equiv -\infty $;

  2. $\varphi $ is upper semicontinuous;

  3. for any complex line $L\subseteq \mathbb {C}^ n$ and any connected component $U$ of $L\cap \Omega $, the restriction $\varphi |_ U$ is either subharmonic or constantly $-\infty $.
    Note. An extremely common mistake in the literature is to replace 3 by the condition that $\varphi $ is locally integrable and $\mathrm{dd}^{\mathrm{c}}\varphi \geq 0$ in the sense of currents. For a concrete counterexample, consider a function $\varphi $ that takes a constant value $0$ at all but one single point, at which the value of $\varphi $ is $1$.

When $n=0$, the only domain $\Omega $ is the singleton. In this case, a plurisubharmonic function on $\Omega $ is a real-valued function on $\Omega $.

The set of plurisubharmonic functions on $\Omega $ is denoted by $\mathrm{PSH}(\Omega )$.

A plurisubharmonic function is also called a psh function for short. The relevant notations are indicated in 1.1.
Note. Recall that most figures in this book are somewhat misleading: We usually draw a complex dimension as a real dimension. The figures should not be read literally!

Example 1.1.4. When $n=0$, we have a canonical bijection $\mathrm{PSH}(\Omega )\cong \mathbb {R}$.

Example 1.1.5.When $n=1$, we have $\mathrm{PSH}(\Omega )=\mathrm{SH}(\Omega )$.

Similar to theorem 1.1.2, we have a rigidity theorem for plurisubharmonic functions as well.

Theorem 1.1.6. Let $\varphi \colon \Omega \rightarrow [-\infty ,\infty )$ be a measurable function. Then the following are equivalent:

  1. $\varphi $ is locally integrable and $\mathrm{dd}^{\mathrm{c}}\varphi \geq 0$;

  2. $\varphi $ coincides almost everywhere with a plurisubharmonic function $\psi $ on $\Omega $.

Moreover, the plurisubharmonic function $\psi $ is unique.

Here, the operator $\mathrm{dd}^{\mathrm{c}}$ is normalized so that
\[ \mathrm{dd}^{\mathrm{c}}=\frac{\mathrm{i}}{2\pi }\partial \overline{\partial }. \]

For the proof, we refer to [Proposition 1.43, GZ17].

Plurisubharmonic functions have nice functorialities:

Proposition 1.1.7. Let $n'\in \mathbb {N}$ and $\Omega '\subseteq \mathbb {C}^{n'}$ be a domain. Given any holomorphic map $f\colon \Omega \rightarrow \Omega '$ and any $\varphi \in \mathrm{PSH}(\Omega ')$, exactly one of the following cases occurs:

  1. $f^*\varphi \equiv -\infty $;

  2. $f^*\varphi \in \mathrm{PSH}(\Omega )$.

We refer to [Proposition 1.44, GZ17] for the proof

For each $n\in \mathbb {N}$, $a\in \mathbb {C}^ n$ and $r>0$, we write

1.1
\begin{equation} \label{eq:Bnar} B_ n(a,r)=\left\{ z\in \mathbb {C}^ n: |z-a|<r \right\} . \end{equation}

Proposition 1.1.8. Let $\varphi \in \mathrm{PSH}(B_ n(a,r_0))$ for some $r_0>0$. Then the function

\[ (-\infty ,\log r_0)\rightarrow \mathbb {R},\quad \log r\mapsto \sup _{B_ n(a,r)}\varphi \]

is convex and increasing.

See [Theorem 4.1.13, Hor07] for the case $n>1$ and [Corollary 2.4, Bou17] for the general case.

Proposition 1.1.9. Let $a<b$ be two real numbers. Let $f\colon (a,b)\rightarrow [-\infty ,\infty )$ be a function. Define

\[ g\colon \{ z\in \mathbb {C}:a<\operatorname{Re}z<b\} \rightarrow [-\infty ,\infty ),\quad z\mapsto f(\operatorname{Re}z). \]

Suppose that $g$ is subharmonic. Then $f$ is convex. In particular, $f$ takes real values only.

See [Theorem 2.12, HK76] for a more general result.
