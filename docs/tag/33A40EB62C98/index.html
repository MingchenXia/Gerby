Chart capacity comparison

From Foundations of pluripotential theory · Lemma 16.1.1

Lemma 16.1.1. Let $D$ and $D'$ be coordinate charts of $X$, identified with bounded open subsets of $\mathbb C^ n$.

  1. For every compact set $L\subset D\cap D'$ there is a constant $c$ such that $\operatorname {Cap}_ D(E)\leq c\operatorname {Cap}_{D'}(E)$ for every Borel set $E\subset L$.

  2. If $E\subset X$ is pluripolar, then $\operatorname {Cap}_ D^*(E\cap D)=0$.

  3. If a Borel function $f\colon X\to [-\infty ,+\infty ]$ is quasi-continuous on each chart of an atlas of $X$, then it is quasi-continuous on every coordinate chart.

Proof. Assertions (1) and (3) are contained in lemma 15.6.1: (1) is its inequality for Borel sets, applied with the roles of $D$ and $D'$ exchanged, and (3) is its final assertion.

For (2) we first observe that if $W\subset D$ is open, then every competitor $v$ for $\operatorname {Cap}_ D$ restricts to a plurisubharmonic function on $W$ with values in $[0,1]$, and the restriction of the Bedford–Taylor measure $(\mathrm{dd}^{\mathrm{c}}v)^ n$ to $W$ is the Bedford–Taylor measure of this restriction. Hence $\operatorname {Cap}_ D(E)\leq \operatorname {Cap}_ W(E)$ for every Borel set $E\subset W$, and, taking infima over the open sets $G$ with $A\subset G\subset W$, also $\operatorname {Cap}_ D^*(A)\leq \operatorname {Cap}_ W^*(A)$ for every set $A\subset W$.

Now cover $D$ by countably many open balls $B_ k$, in the coordinates of $D$, with $\overline{B_ k}\subset D$. Since the condition in definition 10.1.1 is local, $E\cap B_ k$ is pluripolar in $B_ k$, so $\operatorname {Cap}_{B_ k}^*(E\cap B_ k)=0$ by theorem 10.1.4. By the observation above, $\operatorname {Cap}_ D^*(E\cap B_ k)=0$, and the countable subadditivity of $\operatorname {Cap}_ D^*$ (proposition 9.3.3) gives $\operatorname {Cap}_ D^*(E\cap D)=0$. $\square$
