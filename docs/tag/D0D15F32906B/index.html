14.20 Local density and boundary controlD0D15F32906B

From Singularities in Hermitian pluripotential theory · 14.20 Local density and boundary control

Theorem 14.17.1 requires a smooth positive density on the whole regular locus of a global strict barrier, and the global minimum of the difference between the solution and the barrier drives its proof. If the density is smooth and positive only on a smaller open set, smoothness can fail there. A bounded solution with minimal singularities can be discontinuous on a ball where its density is constant (theorem 14.20.4), and a locally Lipschitz plurisubharmonic function with constant density need not be $C^1$ (example 14.20.5). Boundary data give a different route to regularity: if the solution has smooth boundary values on small balls, uniqueness for the bounded Dirichlet problem identifies it with the smooth Dirichlet solution.

In this section $\theta $ is a smooth real $(1,1)$-form on $X$, and $\rho \in \mathrm{PSH}(X,\theta )$ satisfies $\theta +\mathrm{dd}^{\mathrm{c}}\rho \geq \varepsilon \omega $ for some $\varepsilon >0$; in particular $\theta $ is big. We fix an open set $\Omega \subset X$ on which $\rho $ is smooth and $\mathrm{d}\theta =0$.
