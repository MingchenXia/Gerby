Lemma 14.12.1E6E5D71344DD

Lemma 14.12.1. Let $B\Subset \Omega $ be a coordinate ball, and let $u,v$ be bounded $\theta $-plurisubharmonic functions on $B$. Assume

\[ \liminf _{x\to \partial B}(u-v)(x)\geq 0, \qquad \mathbf1_{\{ u<v\} }\mathrm{MA}_\theta (u)\leq \mathbf1_{\{ u<v\} }\mathrm{MA}_\theta (v). \]

Then $u\geq v$ on $B$.

Proof. Fix $\varepsilon >0$ and set $v_\varepsilon =\max (u,v-\varepsilon )$, which equals $u$ near the boundary. We claim that

\[ \mathrm{MA}_\theta (u)\leq \mathrm{MA}_\theta (v_\varepsilon ) \]

throughout $B$. On $\{ u>v-\varepsilon \} $ this follows from locality, since $v_\varepsilon =u$ there. On $\{ u\leq v-\varepsilon \} $ it follows from ordered contact and from the assumed inequality, which applies because this set is contained in $\{ u<v\} $.

Let $q$ be the plurisubharmonic envelope on $B$ of the obstacle $u-v_\varepsilon $, in the sense of (1.9). This obstacle is bounded, quasi-continuous and zero near the boundary. Hence it lies between $Ah$ and zero for a sufficiently large $A$, where $h<0$ is a smooth strictly plurisubharmonic defining function for the ball. Thus $q$ tends to zero at the boundary, and (1.9) shows that $(\mathrm{dd}^{\mathrm{c}}q)^ n$ is carried by $D=\{ q=u-v_\varepsilon \} $.

Since $q\leq u-v_\varepsilon $ quasi-everywhere, the canonical representatives satisfy $q+v_\varepsilon \leq u$. Ordered contact, followed by the measure inequality above, yields

\[ \mathbf1_ D\mathrm{MA}_\theta (q+v_\varepsilon ) \leq \mathbf1_ D\mathrm{MA}_\theta (u) \leq \mathbf1_ D\mathrm{MA}_\theta (v_\varepsilon ). \]

The positive expansion of $(\theta _{v_\varepsilon }+\mathrm{dd}^{\mathrm{c}}q)^ n$ contains both $\mathrm{MA}_\theta (v_\varepsilon )$ and $(\mathrm{dd}^{\mathrm{c}}q)^ n$. Thus $\mathbf1_ D(\mathrm{dd}^{\mathrm{c}}q)^ n=0$, and since $(\mathrm{dd}^{\mathrm{c}}q)^ n$ is carried by $D$, we get $(\mathrm{dd}^{\mathrm{c}}q)^ n=0$. The classical Bedford–Taylor comparison principle for bounded plurisubharmonic functions with zero boundary values implies $q=0$. Consequently $u\geq v_\varepsilon $, first quasi-everywhere and then everywhere. Finally let $\varepsilon \downarrow 0$. $\square$
