Envelope system over $\theta $

From Singularities in Hermitian pluripotential theory · Definition 25.2.2

Definition 25.2.2. An envelope system over $\theta $, with parameters $a<c$, is a family

\[ \boldsymbol \Gamma =(\Gamma ^\eta )_{\eta \in \mathscr H(X)}, \qquad \Gamma ^\eta \in \mathscr T_{a,c}(\theta +\eta ), \]

such that

25.3
\begin{equation} \label{eq:hermitian-system-compatibility} \Gamma ^\eta =P_{\theta +\eta }[\Gamma ^{\eta '}]_{\mathcal I} \quad \hbox{whenever }\eta \geq \eta '. \end{equation}

Write $\mathscr S_{a,c}(\theta )$ for the set of these systems, ordered componentwise. For $\Gamma \in \mathscr T_{a,c}(\theta )$, set

\[ \mathsf E(\Gamma )^\eta =P_{\theta +\eta }[\Gamma ]_{\mathcal I} \qquad (\eta \in \mathscr H(X)). \]

A system is realized in the background $\theta $ if it equals $\mathsf E(\Gamma )$ for some $\Gamma \in \mathscr T_{a,c}(\theta )$.
