Corollary 23.2.10F6950D5704C9

Corollary 23.2.10.F6950D5704C9 If $X$ carries a strictly LCK metric, then no class in $H^{1,1}_{\mathrm{BC}}(X,\mathbb R)$ is big. In particular, $X$ does not belong to Fujiki's class $\mathcal C$.

Proof. If there were a big class, the modification criterion recalled in section 10.10 would give a modification $\pi :Y\to X$ with $Y$ compact Kähler. The form $\pi ^*\kappa _\lambda $ is closed and de Rham exact, so the $\partial \bar\partial $-lemma on $Y$ gives a smooth real function $h$ on $Y$ with $\pi ^*\kappa _\lambda =\mathrm{dd}^{\mathrm{c}}h$. Since $\pi $ has degree one, pushing forward gives the current identity $\kappa _\lambda =\mathrm{dd}^{\mathrm{c}}(\pi _*h)$. By Stokes' theorem, the pairing of this current with a Gauduchon form is zero, which contradicts (23.2.8) for the Gauduchon representative of the LCK structure. $\square$
