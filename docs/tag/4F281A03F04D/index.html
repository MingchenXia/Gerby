Classes of convex functions

From Singularities in global pluripotential theory · A.3 Classes of convex functions

Let $N$ be a real vector space of finite dimension and $M$ be the dual vector space.

We shall fix a convex body $P\subseteq M$.

The following classes are introduced in [BB13].

Definition A.3.1. We define the set $\mathcal{P}(N,P)$ as the set of proper convex functions $F\in \mathrm{Conv}(N)$ such that $F\preceq \operatorname{Supp}_ P$.

We define the set $\mathcal{E}^{\infty }(N,P)$ as the set of closed convex functions $F\in \mathrm{Conv}(N)$ such that $F\sim \operatorname{Supp}_ P$.

We define the set $\mathcal{E}(N,P)$ as follows: Suppose that $\operatorname{Int}P=\varnothing $. Then $\mathcal{E}(N,P)\coloneqq \mathcal{P}(N,P)$; otherwise, let

\[ \mathcal{E}(N,P)=\left\{ F\in \mathcal{P}(N,P) : P=\overline{\nabla F(N)} \right\} . \]

We define the set $\mathcal{E}^1(N,P)$ as the subset of $\mathcal{E}(N,P)$ consisting of $F\in \mathcal{E}(N,P)$ with

\[ \int _ P F^*\, \mathrm{d}\operatorname{vol}<\infty , \]

where $\mathrm{d}\operatorname{vol}$ is any Lebesgue measure on $M$.

Observe that for any $F\in \mathcal{P}(N,P)$, we have $\operatorname{Dom}F=N$ and $F$ is necessarily closed.

Proposition A.3.2. We have

\[ \mathcal{E}^{\infty }(N,P)\subseteq \mathcal{E}^{1}(N,P)\subseteq \mathcal{E}(N,P) \subseteq \mathcal{P}(N,P). \]

Proof. When $\operatorname{Int}P=\varnothing $, the assertion is clear. We assume that $\operatorname{Int}P\neq \varnothing $. The second inclusion follows from the definition. We only handle the first inequality. Take $F\in \mathcal{E}^{\infty }(N,P)$. By definition, $F\sim \operatorname{Supp}_ P$ and hence $F^*\sim \chi _ P$. It follows that $P=\operatorname{Dom}F^*$.

By proposition A.2.12, we already know that

\[ \nabla F(N)\subseteq P=\operatorname{Dom}F^*. \]

On the other hand, by proposition A.2.9, we have

\[ \operatorname{Int}P\subseteq \nabla F(N). \]

So it follows that

\[ P=\overline{\nabla F(N)}. \]

It is clear that $F^*\sim \chi _ P$ is integrable. $\square$

Proposition A.3.3. For any $F\in \mathcal{E}^{\infty }(N,P)$, we have $F^*|_{M\setminus P}\equiv \infty $ and $F^*$ is bounded on $P$.

Proof. From $F\sim \operatorname{Supp}_ P$, we take the Legendre transform to get $F^*\sim \operatorname{Supp}_ P^*=\chi _ P$, where we applied example A.2.3. $\square$

Definition A.3.4. We endow the topology of pointwise convergence on $\mathcal{P}(N,P)$.

Note that this topology coincides with the compact-open topology. See [Theorem 10.8, Roc70].

Proposition A.3.5. Let $F\in \mathcal{P}(N,P)$. Then there is a decreasing sequence $F_ j\in \mathcal{E}^{\infty }(N,P)\cap C^{\infty }(N)$ converging to $F$.

See [Lemma 2.2, BB13]. We observe that the point $0\in N$ plays a special role since it does in the definition of the support function.

Proposition A.3.6. For any $F\in \mathcal{P}(N,P)$, we have

\[ \max _{N}(F-\operatorname{Supp}_ P)=F(0). \]

Proof. It follows from (A.11) that

\[ \sup _{N}(F-\operatorname{Supp}_ P)\leq F(0). \]

The equality is clearly obtained at $0\in N$. $\square$

Lemma A.3.7. Let $P'\subseteq M$ be another convex body. Then for any $F\in \mathcal{P}(N,P)$ and $F'\in \mathcal{P}(N,P')$, we have

\[ F+F'\in \mathcal{P}(N,P+P'). \]

Moreover, let $F$ and $F'$ be real-valued convex functions on $N$. Assume that $\operatorname{Dom}F^*$ is bounded. Then

\[ \overline{\nabla F(N)}+\overline{\nabla F'(N)}=\overline{\nabla (F+F')(N)}. \]

In particular, if $F\in \mathcal{P}(N,P)$, $F'\in \mathcal{P}(N,P')$ and

\[ \overline{\nabla F(N)}=P,\quad \overline{\nabla F'(N)}=P', \]

then $F+F'\in \mathcal{E}(N,P+P')$.

Proof. The former assertion follows immediately from the observation

\[ \operatorname{Supp}_{P+P'}=\operatorname{Supp}_ P+\operatorname{Supp}_{P'}. \]

We prove the gradient-image equality. In view of proposition A.2.9, this means

A.12
\begin{equation} \label{eq:overlineDom_temp1} \overline{\operatorname{Dom}(F+F')^*}=\overline{\operatorname{Dom}F^*}+\overline{\operatorname{Dom}F'{}^*}. \end{equation}

It follows from proposition A.2.11 that

\[ \operatorname{Dom}(F+F')^*=\operatorname{Dom}F^*+\operatorname{Dom}F'{}^*. \]
Since $\overline{\operatorname{Dom}F^*}$ is compact, (A.12) follows

Finally, under the assumptions in the last assertion, the former assertion gives $F+F'\in \mathcal{P}(N,P+P')$. If $\operatorname{Int}(P+P')=\varnothing $, this is exactly the definition of $\mathcal{E}(N,P+P')$. Otherwise, the gradient-image equality gives

\[ \overline{\nabla (F+F')(N)}=P+P', \]

so again $F+F'\in \mathcal{E}(N,P+P')$. $\square$
