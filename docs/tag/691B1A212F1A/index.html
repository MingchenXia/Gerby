Chapter 13 · Singularity types, envelopes, and models · Tag 691B1A212F1A

Big class bounded locus

From Foundations of pluripotential theory · Lemma 16.2.3

Lemma 16.2.3. Suppose that $\{ \theta \} $ is big. There is a proper analytic subset $A\subset X$, the pole set of a $\theta $-plurisubharmonic function with analytic singularities, such that every potential with minimal singularities is locally bounded on $X\setminus A$. The set $A$ is closed and pluripolar; in particular $\mu _ u(A)=0$ for every $u\in \mathrm{PSH}(X,\theta )$.

Proof. By proposition 14.3.5, the big class contains a Kähler current $\theta +\mathrm{dd}^{\mathrm{c}}\psi $ whose potential $\psi \in \mathrm{PSH}(X,\theta )$ has analytic singularities, and we put $A=\{ \psi =-\infty \} $. Every point of $X$ has a connected coordinate neighborhood $V$ on which $\psi =c\log \sum _ i|g_ i|^2+b$, with $c>0$, $b$ bounded and holomorphic functions $g_ i$ that do not all vanish identically (definition 13.1.5). Thus $A\cap V$ is the common zero set of the $g_ i$, so $A$ is an analytic subset of $X$, different from $X$, and it is closed and pluripolar, being locally the pole set of the plurisubharmonic function $\log \sum _ i|g_ i|^2$. On $V\setminus A$ the continuous function $\sum _ i|g_ i|^2$ is positive, so $\psi $ is locally bounded on $X\setminus A$. If $\varphi $ has minimal singularities, then $\psi \leq \varphi +C'$ for a constant $C'$, so $\varphi $ is locally bounded below on $X\setminus A$; it is bounded above, being upper semicontinuous on the compact space $X$. The last assertion holds because non-pluripolar products give no mass to pluripolar sets. $\square$
