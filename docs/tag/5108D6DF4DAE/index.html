Corollary 20.1.345108D6DF4DAE

Corollary 20.1.34.5108D6DF4DAE There is a canonical bijection between the following two sets:

  1. 43F5185C6427

    The set of

    \[ \varprojlim _{\omega } \left( \mathcal{Z}_+(X,\alpha +\omega )_{>0}/\sim _{\mathcal{I}} \right), \]

    where $\omega $ runs over the directed set of Kähler forms on $X$;

  2. 11B8881EEBEC

    the set of augmented nef b-divisors over $X$ with cohomology class $\alpha $.

Proof. Apply corollary 20.1.31 to the non-divisorial parts and use Siu's decomposition on $X$ to record the divisorial part. The convergence condition in definition 20.1.32 is exactly the condition that the roots of the non-divisorial parts converge to the prescribed cohomology class $\alpha $. $\square$
