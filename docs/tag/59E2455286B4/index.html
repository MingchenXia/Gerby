Theorem A.4.759E2455286B4

From Singularities in global pluripotential theory · Theorem A.4.7

Theorem A.4.7. There is a symmetric map assigning to every $n$-tuple of finite convex functions $F_1,\ldots ,F_ n$ on $N_{\mathbb R}$ a positive Radon measure

\[ \operatorname{MA}_{\mathbb R}(F_1,\ldots ,F_ n) \]

on $N_{\mathbb R}$ with the following properties:

  1. For every $q\in \mathbb Z_{>0}$, finite convex functions $F_1,\ldots ,F_ q$ on $N_{\mathbb R}$, and $\lambda _1,\ldots ,\lambda _ q\geq 0$,

    \[ \operatorname{MA}_{\mathbb R}(\lambda _1F_1+\cdots +\lambda _ qF_ q) =\sum _{i_1,\ldots ,i_ n=1}^ q \lambda _{i_1}\cdots \lambda _{i_ n} \operatorname{MA}_{\mathbb R}(F_{i_1},\ldots ,F_{i_ n}). \]

  2. For every finite convex function $F$ on $N_{\mathbb R}$,

    \[ \operatorname{MA}_{\mathbb R}(F,\ldots ,F)=\operatorname{MA}_{\mathbb R}(F). \]

  3. The map $\operatorname{MA}_{\mathbb R}$ is additive and positively homogeneous of degree $1$ in each entry. In other words, for finite convex functions $F,G,F_2,\ldots ,F_ n$ on $N_{\mathbb R}$ and $\lambda ,\mu \geq 0$,

    \[ \operatorname{MA}_{\mathbb R}(\lambda F+\mu G,F_2,\ldots ,F_ n) =\lambda \operatorname{MA}_{\mathbb R}(F,F_2,\ldots ,F_ n) +\mu \operatorname{MA}_{\mathbb R}(G,F_2,\ldots ,F_ n). \]
