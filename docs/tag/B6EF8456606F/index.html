Corollary 3.1.8

From Singularities in global pluripotential theory · Corollary 3.1.8

Corollary 3.1.8. Let $\varphi ,\psi \in \mathrm{PSH}(X,\theta )$. Let

\[ \eta \coloneqq \operatorname *{sup}_{C>0}{}\! {}^{*} (\varphi +C)\land \psi .\footnotemark \]
Note. Using the terminology to be introduced in definition 3.1.19, we can also write $\eta =P_{\theta }[\varphi ](\psi )$.
Assume that $\eta \not\equiv -\infty $ (for example when $\varphi \preceq \psi $). Then
\[ \theta _{\eta }^ n\leq \mathds {1}_{\{ \eta =\psi \} }\, \theta _{\psi }^ n. \]

Proof. Thanks to 3.1.3, for each $C>0$, we have

\[ \begin{aligned} \theta _{(\varphi +C)\land \psi }^ n\leq & \mathds {1}_{\{ (\varphi +C)\land \psi =\varphi +C\} }\, \theta _{\varphi }^ n+\mathds {1}_{\{ (\varphi +C)\land \psi =\psi \} }\, \theta _{\psi }^ n\\ \leq & \mathds {1}_{\{ \varphi +C\leq \psi \} }\, \theta _{\varphi }^ n+\mathds {1}_{\{ \eta =\psi \} } \, \theta _{\psi }^ n. \end{aligned} \]

We wish to let $C\to \infty $. The dominated convergence theorem and the semicontinuity theorem corollary 2.4.9 give, as $C\to \infty $,

\[ \mathds {1}_{\{ \varphi +C\leq \psi \} } \theta _{\varphi }^ n\rightharpoonup 0,\quad \theta _{(\varphi +C)\land \psi }^ n\rightharpoonup \theta _{\eta }^ n. \]

So we conclude that

\[ \theta _{\eta }^ n\leq \mathds {1}_{\{ \eta =\psi \} } \, \theta _{\psi }^ n. \]

This completes the proof. $\square$
