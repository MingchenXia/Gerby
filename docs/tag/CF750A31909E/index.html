From Singularities in global pluripotential theory · Remark 13.3.4

Remark 13.3.4. When $\{ \theta \} $ is a Hodge class and $\Gamma $ is induced by a test configuration as in example 9.3.9 and 9.3.10, our Duistermaat–Heckman measure coincides with the more traditional definition of [Section 3.2, BHJ17]. This is explained in [Remark 7.17, Xia21].
