Theorem 21.13.5346AFD20390FF

Theorem 21.13.53.46AFD20390FF There are canonical bijections4 between the following sets:

  1. B36269428F96

    The set of $\varphi \in \mathrm{PSH}_{\mathrm{tor}}(X,\theta )$;

  2. BBC2A49C71B9

    the set of $F\in \mathcal{P}(N_{\mathbb {R}},P_ D)$, and

  3. 40A0E4A3390B

    the set of closed proper convex functions $G\in \mathrm{Conv}(M_{\mathbb {R}})$ satisfying

    \[ G|_{M_{\mathbb {R}}\setminus P_ D}\equiv \infty . \]
4. ↩ In the earlier version of these constructions, I required additional conditions in 2 and 3, namely $F\preceq F_{V_{\theta }}$ and $G\succeq G_{V_{\theta }}$ respectively. These conditions can be removed, since $G_{V_{\theta }}$ is always bounded, as suggested by Robert Berman. See theorem 21.13.45.

Proof. The proof is similar to that of theorem 21.12.13, but due to its importance, we give the details. Again, the correspondence between 2 and 3 follows easily from proposition 21.11.38.

Given $\varphi $, we can construct $F_{\varphi }$ in 2 as explained earlier in (21.13.26). Conversely, suppose that $F\in \mathcal{P}(N_{\mathbb {R}},P_ D)$, then $F\preceq F_{V_{\theta }}$ by theorem 21.13.45. Then

\[ \operatorname{Trop}^*\left(F-F_{\theta }\right)\in \mathrm{PSH}\left(T(\mathbb {C}),\theta |_{T(\mathbb {C})}\right) \]

by 21.12.7. Since $F\preceq F_{V_{\theta }}$, we see that $\operatorname{Trop}^*(F-F_{\theta })$ is bounded from above. It follows that Grauert–Remmert's extension theorem theorem 5.14.10 is applicable, and this function extends to a unique $\theta $-psh function $\varphi $. The uniqueness of the extension guarantees that $\varphi \in \mathrm{PSH}_{\mathrm{tor}}(X,\theta )$.

The two maps are inverse to each other by construction. $\square$
