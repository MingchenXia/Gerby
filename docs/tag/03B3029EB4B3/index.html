10.4 Countable selections and plurifine locality03B3029EB4B3

From Foundations of pluripotential theory · 10.4 Countable selections and plurifine locality

The plurifine topology is in general not Lindelöf: in dimension one it is the classical fine topology of $\mathbb C=\mathbb R^2$, which is not Lindelöf by example 5.1.7. As in theorem 5.4.1, countability is recovered outside an exceptional set, which is now pluripolar. Since Bedford–Taylor products of locally bounded potentials do not charge pluripolar sets (corollary 10.2.2(3)), this allows us to pass from the local identity of lemma 10.4.2 to locality on arbitrary plurifine open sets. Applied to the truncations $\max \{ u,-k\} $ of unbounded potentials, plurifine locality shows that their products for different levels $k\ge m$ agree on the set where all the potentials exceed $-m$.

Theorem 10.4.1. Let $X$ be a complex manifold with a countable basis.

  1. For every family $(U_ i)_{i\in I}$ of plurifine open subsets of $X$, there is a countable set $J\subset I$ such that $\bigcup _{i\in I}U_ i\setminus \bigcup _{j\in J}U_ j$ is pluripolar.

  2. Every plurifine open set $U\subset X$ contains countably many sets $A_ k=Q_ k\cap \{ \psi _ k>0\} $, where each $Q_ k$ is a coordinate ball and $\psi _ k$ is a bounded plurisubharmonic function on $Q_ k$, such that $U\setminus \bigcup _ kA_ k$ is pluripolar. In particular, $U$ contains the Borel set $V=\bigcup _ kA_ k$, and $U\setminus V$ is pluripolar. Consequently, if $C\subset X$ is a chart domain and $\mu $ is a positive Borel measure on $C$ for which every pluripolar subset of $C$ has outer measure zero, then $U\cap C$ is measurable for the completion of $\mu $.

Proof. Since $X$ has a countable basis, it is covered by countably many charts; in each chart, the coordinate balls with rational centers and radii and with closure in the chart domain form a countable basis. Let $\mathcal Q$ be the union of these countable families; it is a countable basis of $X$.

(1) Let $U=\bigcup _ iU_ i$; if $I$ is empty, take $J$ empty. We call a set basic if it has the form $Q\cap \{ \psi >0\} $, where $Q\in \mathcal Q$ and $\psi $ is a bounded plurisubharmonic function on a neighborhood of $\overline Q$. Every point $a\in U$ lies in a basic set contained in some $U_ i$: if $a\in U_ i$, then proposition 10.3.2(2) gives a ball $B$ and a bounded plurisubharmonic function $\psi $ on a neighborhood of $\overline B$ with $a\in B\cap \{ \psi >0\} \subset U_ i$, and it suffices to choose $Q\in \mathcal Q$ with $a\in Q\subset B$.

Fix $Q\in \mathcal Q$, and let $\Psi _ Q$ be the set of bounded plurisubharmonic functions $\psi $ on neighborhoods of $\overline Q$ for which the basic set $Q\cap \{ \psi >0\} $ is contained in some $U_ i$. If $\Psi _ Q$ is empty, we put $P_ Q=\varnothing $ and select nothing for this $Q$. Otherwise, we may assume that all members of $\Psi _ Q$ take values in $[-1,1]$ on $Q$, since replacing $\psi $ by $\psi /c$, where $c>0$ bounds $|\psi |$ on $Q$, does not change $Q\cap \{ \psi >0\} $.

Let $F_ Q$ be the pointwise supremum of the members of $\Psi _ Q$ on $Q$. By Choquet's lemma (lemma 3.4.1) there are $\psi _{Q,1},\psi _{Q,2},\ldots $ in $\Psi _ Q$ whose supremum $F_ Q'$ satisfies $(F_ Q')^*=F_ Q^*$. By corollary 10.2.2(1) and the last assertion of theorem 10.1.4, the set $P_ Q=\{ F_ Q<F_ Q^*\} \cup \{ F_ Q'<(F_ Q')^*\} $ is pluripolar in $Q$, and hence in $X$. If $z\in Q\setminus P_ Q$ and $\psi (z)>0$ for some $\psi \in \Psi _ Q$, then $F_ Q'(z)=F_ Q^*(z)=F_ Q(z)>0$, so $\psi _{Q,k}(z)>0$ for some $k$. Therefore

\[ \bigcup _{\psi \in \Psi _ Q}\bigl (Q\cap \{ \psi >0\} \bigr )\subset P_ Q\cup \bigcup _ k\bigl (Q\cap \{ \psi _{Q,k}>0\} \bigr ). \]

For each $Q$ and $k$ choose an index $i(Q,k)\in I$ with $Q\cap \{ \psi _{Q,k}>0\} \subset U_{i(Q,k)}$, and let $J$ be the countable set of these indices. Every point of $U$ lies in some basic set $Q\cap \{ \psi >0\} $ with $\psi \in \Psi _ Q$, so $U\setminus \bigcup _{j\in J}U_ j$ is contained in $\bigcup _ QP_ Q$. This countable union of pluripolar sets is pluripolar by theorem 10.1.4.

(2) Apply the construction of (1) to the family consisting of the single set $U$. It selects countably many sets $Q\cap \{ \psi _{Q,k}>0\} $, where $Q\in \mathcal Q$ is a coordinate ball and $\psi _{Q,k}$ restricts to a bounded plurisubharmonic function on $Q$; these sets are contained in $U$, and their union $V$ satisfies $U\setminus V\subset \bigcup _ QP_ Q$, which is pluripolar. Each selected set is Borel, because $\psi _{Q,k}$ is upper semicontinuous, so the countable union $V$ is Borel. Finally, let $C$ and $\mu $ be as in the statement. The set $(U\setminus V)\cap C$ is pluripolar in $C$, so it has outer $\mu $-measure zero and is a null set for the completion of $\mu $. Since $U\cap C=(V\cap C)\cup \bigl ((U\setminus V)\cap C\bigr )$ and $V\cap C$ is Borel, $U\cap C$ is measurable for the completion of $\mu $. $\square$

We now turn to Bedford–Taylor products. The first step is their locality on a single superlevel set of a plurisubharmonic function, which we derive from their locality on the sets $\{ u>v\} $ (proposition 9.2.7).

Lemma 10.4.2. Let $\Omega \subset \mathbb C^ n$ be open, let $T$ be a closed positive current of bidimension $(r,r)$ on $\Omega $, let $u$ and $v$ be locally bounded plurisubharmonic functions on $\Omega $, and let $t\in \mathrm{PSH}(\Omega )$. If $u=v$ on $\{ t>0\} $, then, for every integer $0\le p\le r$,

\[ \mathbf1_{\{ t>0\} }(\mathrm{dd}^{\mathrm{c}}u)^ p\wedge T =\mathbf1_{\{ t>0\} }(\mathrm{dd}^{\mathrm{c}}v)^ p\wedge T. \]

Proof. Replacing $t$ by $\max \{ t,0\} $, which is plurisubharmonic (proposition 8.2.5) and has the same set $\{ t>0\} $, we may assume that $t\ge 0$. Then $t$ is locally bounded, because plurisubharmonic functions are bounded above on compact sets, and $u+\varepsilon t$ is a locally bounded plurisubharmonic function for every $\varepsilon >0$. For $\varepsilon >0$ put $w_\varepsilon =\max \{ u+\varepsilon t,v\} $. On $\{ t>0\} $ we have $u+\varepsilon t>u=v$, so $\{ t>0\} \subset \{ u+\varepsilon t>v\} $, and proposition 9.2.7, applied to $u+\varepsilon t$ and $v$, gives

\[ \mathbf1_{\{ t>0\} }(\mathrm{dd}^{\mathrm{c}}w_\varepsilon )^ p\wedge T=\mathbf1_{\{ t>0\} }(\mathrm{dd}^{\mathrm{c}}(u+\varepsilon t))^ p\wedge T. \]

Multiplying by $t$, which vanishes outside $\{ t>0\} $, we obtain $t(\mathrm{dd}^{\mathrm{c}}w_\varepsilon )^ p\wedge T=t(\mathrm{dd}^{\mathrm{c}}(u+\varepsilon t))^ p\wedge T$. As $\varepsilon $ decreases to zero along a sequence, $w_\varepsilon $ decreases to $\max \{ u,v\} $ and $u+\varepsilon t$ decreases to $u$, because $t\ge 0$. The weighted form of theorem 9.2.5, with the constant sequence of weights equal to $t$, therefore yields

\[ t(\mathrm{dd}^{\mathrm{c}}\max \{ u,v\} )^ p\wedge T=t(\mathrm{dd}^{\mathrm{c}}u)^ p\wedge T. \]

Interchanging the roles of $u$ and $v$, we also get $t(\mathrm{dd}^{\mathrm{c}}\max \{ u,v\} )^ p\wedge T=t(\mathrm{dd}^{\mathrm{c}}v)^ p\wedge T$, and hence $t(\mathrm{dd}^{\mathrm{c}}u)^ p\wedge T=t(\mathrm{dd}^{\mathrm{c}}v)^ p\wedge T$. Finally, multiply the coefficient measures of both sides by $1/(t+\delta )$ and let $\delta \downarrow 0$. Since $t/(t+\delta )\to \mathbf1_{\{ t>0\} }$ pointwise and boundedly, dominated convergence with respect to the total variations of the coefficient measures gives the assertion. $\square$

Bedford–Taylor products are local in the plurifine topology, in the following sense.

Theorem 10.4.3. Let $X$ be a complex manifold of dimension $n$, let $1\le q\le n$ be an integer, and let $u_1,\ldots ,u_ q$ and $v_1,\ldots ,v_ q$ be locally bounded plurisubharmonic functions on $X$. If $u_ l=v_ l$ on a plurifine open set $W\subset X$ for every $l$, then

\[ \mathbf1_ W\mathrm{dd}^{\mathrm{c}}u_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}u_ q =\mathbf1_ W\mathrm{dd}^{\mathrm{c}}v_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}v_ q. \]

Here $W$ need not be Borel (example 10.3.5). It is measurable for the completions of the total variations of the coefficient measures of both products, and $\mathbf1_ W$ acts on these completed measures; up to null sets of these measures, $W$ coincides with a Borel set.

Proof. The identity and the measurability of $W$ are local properties, so we may assume that $X$ is an open ball in $\mathbb C^ n$; by proposition 10.3.2(3), the intersection of $W$ with this ball is plurifine open in the ball. Write $S_ u=\mathrm{dd}^{\mathrm{c}}u_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}u_ q$ and $S_ v=\mathrm{dd}^{\mathrm{c}}v_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}v_ q$. We first prove the identity on sets of the form $Q\cap \{ \psi >0\} $, and then cover $W$ by countably many such sets up to a pluripolar set, which the products do not charge.

Step 1: basic sets. We show that $\mathbf1_ AS_ u=\mathbf1_ AS_ v$ whenever $Q\subset X$ is open, $\psi \in \mathrm{PSH}(Q)$ and $A=Q\cap \{ \psi >0\} \subset W$. For every nonempty set $I\subset \{ 1,\ldots ,q\} $, the functions $u_ I=\sum _{l\in I}u_ l$ and $v_ I=\sum _{l\in I}v_ l$ are locally bounded and plurisubharmonic on $Q$, and they coincide on $A$, because $u_ l=v_ l$ on $W$. By lemma 10.4.2, applied on $Q$ with $t=\psi $, $T=1$ and $p=q$, we have $\mathbf1_ A(\mathrm{dd}^{\mathrm{c}}u_ I)^ q=\mathbf1_ A(\mathrm{dd}^{\mathrm{c}}v_ I)^ q$.

We now recover $S_ u$ from the products $(\mathrm{dd}^{\mathrm{c}}u_ I)^ q$ by polarization. For a multi-index $\alpha \in \mathbb N^ q$ with $|\alpha |=q$, let $S_ u^\alpha $ be the product of $q$ factors in which $\mathrm{dd}^{\mathrm{c}}u_ l$ occurs $\alpha _ l$ times; it does not depend on the order of the factors, because products of locally bounded plurisubharmonic functions are symmetric (theorem 9.2.5). Since these products are also additive in each factor (proposition 9.1.2(3)), expanding $(\mathrm{dd}^{\mathrm{c}}u_ I)^ q$ with $\mathrm{dd}^{\mathrm{c}}u_ I=\sum _{l\in I}\mathrm{dd}^{\mathrm{c}}u_ l$ gives, exactly as in the multinomial expansion of $(\sum _{l\in I}x_ l)^ q$,

\[ (\mathrm{dd}^{\mathrm{c}}u_ I)^ q=\sum _\alpha \frac{q!}{\alpha !}\, S_ u^\alpha , \]

where $\alpha $ ranges over the multi-indices with $|\alpha |=q$ and $\alpha _ l=0$ for $l\notin I$. Multiplying by $(-1)^{q-|I|}$ and summing over the nonempty sets $I\subset \{ 1,\ldots ,q\} $, we obtain $\sum _\alpha c_\alpha S_ u^\alpha $, summed over all $\alpha $ with $|\alpha |=q$, where $c_\alpha $ is the coefficient of the monomial $x^\alpha $ on the right-hand side of the polarization identity (9.11) with $N=q$ (in which the term with $I=\varnothing $ vanishes). Both sides of that identity are polynomials in $x_1,\ldots ,x_ q$ that agree on $\mathbb R^ q$, so they have the same coefficients: $c_\alpha =q!$ if $\alpha =(1,\ldots ,1)$, and $c_\alpha =0$ otherwise. Since $S_ u^{(1,\ldots ,1)}=S_ u$, we obtain

\[ q!\, S_ u=\sum _{\varnothing \ne I\subset \{ 1,\ldots ,q\} }(-1)^{q-|I|}(\mathrm{dd}^{\mathrm{c}}u_ I)^ q \quad \text{on }Q. \]

The same identity holds for the $v_ l$. Multiplying both identities by $\mathbf1_ A$ and using $\mathbf1_ A(\mathrm{dd}^{\mathrm{c}}u_ I)^ q=\mathbf1_ A(\mathrm{dd}^{\mathrm{c}}v_ I)^ q$, we obtain $\mathbf1_ AS_ u=\mathbf1_ AS_ v$.

Step 2: countable selection. By theorem 10.4.1(2), applied to the ball $X$ and its plurifine open subset $W$, there are countably many sets $A_ k=Q_ k\cap \{ \psi _ k>0\} \subset W$, with $Q_ k\subset X$ open and $\psi _ k\in \mathrm{PSH}(Q_ k)$, whose union $V$ is Borel and such that $W\setminus V$ is pluripolar. By corollary 10.2.2(3), every pluripolar subset of $X$ has outer measure zero for the total variations of the coefficient measures of $S_ u$ and $S_ v$. Hence, by the last assertion of theorem 10.4.1(2), $W$ is measurable for their completions; moreover $W\setminus V$ is a null set for them, so $\mathbf1_ WS_ u=\mathbf1_ VS_ u$ and $\mathbf1_ WS_ v=\mathbf1_ VS_ v$. The Borel sets $A_ k'=A_ k\setminus (A_1\cup \cdots \cup A_{k-1})$ partition $V$, and Step 1 gives $\mathbf1_{A_ k'}S_ u=\mathbf1_{A_ k'}\mathbf1_{A_ k}S_ u=\mathbf1_{A_ k'}\mathbf1_{A_ k}S_ v=\mathbf1_{A_ k'}S_ v$. Summing over $k$, by countable additivity of the coefficient measures, we obtain $\mathbf1_ VS_ u=\mathbf1_ VS_ v$, which proves the theorem. $\square$

Step 1 of this proof works, with the same argument, for products $\mathrm{dd}^{\mathrm{c}}u_1\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}u_ q\wedge T$ with an arbitrary closed positive current $T$, because lemma 10.4.2 does. Step 2 does not: such a current may charge pluripolar sets, and then the exceptional set $W\setminus V$ cannot be neglected. For instance, if $H=\{ z\in \mathbb C^ n:z_1=0\} $, the current of integration $[H]$ of example 7.2.7 has the trace measure $[H]\wedge \beta ^{n-1}$, which is $(n-1)!$ times the $(2n-2)$-dimensional Lebesgue measure of $H$, because the restriction of $\beta ^{n-1}/(n-1)!$ to $H$ is the Euclidean volume form of $H$; so it gives positive mass to $H$, which is pluripolar as the pole set of $\log |z_1|^2$.

Proposition 10.4.4. Let $\Omega \subset \mathbb C^ n$ be open, let $1\le q\le n$ be an integer, and let $u_1,\ldots ,u_ q\in \mathrm{PSH}(\Omega )$. For every integer $m\ge 1$ put

\[ u_ l^{(m)}=\max \{ u_ l,-m\} ,\qquad E_ m=\bigcap _{l=1}^ q\{ u_ l>-m\} ,\qquad S_ m=\mathrm{dd}^{\mathrm{c}}u_1^{(m)}\wedge \cdots \wedge \mathrm{dd}^{\mathrm{c}}u_ q^{(m)}. \]

Then, for all integers $k\ge m\ge 1$,

\[ \mathbf1_{E_ m}S_ k=\mathbf1_{E_ m}S_ m. \]

The restrictions $\mu _ m=\mathbf1_{E_ m}\mu _{S_ m}$ of the trace measures $\mu _{S_ m}$ (definition 7.2.4) increase with $m$, and every pluripolar subset of $\Omega $ has outer measure zero for each $\mu _ m$. Their increasing limit $\mu =\lim _ m\mu _ m$ is a Borel measure on $\Omega $, possibly of infinite mass on compact sets, for which every pluripolar subset of $\Omega $ also has outer measure zero.

Proof. Each set $\{ u_ l>-m\} $ is a subbasic plurifine open set, so $E_ m$ is plurifine open; it is also Borel. On $E_ m$ we have $u_ l>-m$, and hence $u_ l^{(k)}=u_ l=u_ l^{(m)}$ for all $l$ and all $k\ge m$. The truncations are locally bounded plurisubharmonic functions, so theorem 10.4.3 gives $\mathbf1_{E_ m}S_ k=\mathbf1_{E_ m}S_ m$. Taking trace measures, and using $E_ m\subset E_ k$ and the positivity of $\mu _{S_ k}$, we obtain $\mu _ m=\mathbf1_{E_ m}\mu _{S_ k}\le \mathbf1_{E_ k}\mu _{S_ k}=\mu _ k$. By corollary 10.2.2(3), every pluripolar subset of $\Omega $ has outer measure zero for $\mu _{S_ m}$, and hence for $\mu _ m$.

For a Borel set $A\subset \Omega $ put $\mu (A)=\lim _ m\mu _ m(A)\in [0,\infty ]$. If $A$ is the disjoint union of Borel sets $A_ i$, then

\[ \mu (A)=\lim _ m\sum _ i\mu _ m(A_ i)=\sum _ i\lim _ m\mu _ m(A_ i)=\sum _ i\mu (A_ i), \]

by monotone convergence for series of nonnegative terms that increase with $m$. Thus $\mu $ is a Borel measure. Finally, let $N\subset \Omega $ be pluripolar. Since $N$ has outer measure zero for each $\mu _ m$, there are Borel sets $G_{m,i}\supset N$ with $\mu _ m(G_{m,i})<1/i$ for all $m,i\ge 1$. The Borel set $G=\bigcap _{m,i}G_{m,i}$ contains $N$ and satisfies $\mu _ m(G)=0$ for every $m$, hence $\mu (G)=0$. Thus $N$ has outer measure zero for $\mu $. $\square$

In general $\mu $ is not locally finite (example 15.1.6), so a separate local mass estimate is needed before the restrictions $\mathbf1_{E_ m}S_ m$ can define a current of order zero in the limit; this is the subject of chapter 15.
