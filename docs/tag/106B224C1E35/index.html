Proposition 14.3.5106B224C1E35

From Foundations of pluripotential theory · Proposition 14.3.5

Proposition 14.3.5. A class that contains a closed positive current with locally bounded potentials is nef. A class that contains a Kähler current with locally bounded potentials is Kähler. Every big class contains a Kähler current with gentle analytic singularities.

Proof. Write the given current as $\theta +\mathrm{dd}^{\mathrm{c}}\varphi $ with $\varphi \in \mathrm{PSH}(X,\theta )$. If $\varphi $ is bounded, then every $\mathcal I(m\varphi )$ is the unit ideal, so the approximations $G_ m$ are smooth and satisfy $\theta +\mathrm{dd}^{\mathrm{c}}G_ m\geq -(c/m)\omega $; hence the class is nef. If moreover $\theta +\mathrm{dd}^{\mathrm{c}}\varphi \geq \delta \omega $, then $\varphi \in \mathrm{PSH}(X,\theta -\delta \omega )$, and the approximations for the background $\theta -\delta \omega $ satisfy $\theta +\mathrm{dd}^{\mathrm{c}}G_ m\geq (\delta -c/m)\omega $; for large $m$ the smooth form $\theta +\mathrm{dd}^{\mathrm{c}}G_ m$ is a Kähler form in the class. For the last assertion, let $\theta +\mathrm{dd}^{\mathrm{c}}\varphi \geq \delta \omega $ be a Kähler current in a big class, with $\varphi $ not necessarily bounded. The same inequality shows that $\theta +\mathrm{dd}^{\mathrm{c}}G_ m$ is a Kähler current for large $m$, and $G_ m$ has gentle analytic singularities of type $(m^{-1},\mathcal I(m\varphi ))$ by lemma 13.4.1. $\square$
