Singularity order and singularity types

The same bounded-shift preorder on quasi-plurisubharmonic functions on a compact manifold. The Hermitian source distinguishes ordinary type from multiplier-ideal type.

From Singularities in global pluripotential theory · Definition 1.5.2
Definition 1.5.2.Assume that $X$ is compact. Given $\varphi ,\psi \in \mathrm{QPSH}(X)$, we say that $\varphi $ is more singular than $\psi $ and write $\varphi \preceq \psi $
Note. Some people write $\psi \preceq \varphi $.
if there is $C\in \mathbb {R}$ such that $\varphi \leq \psi +C$. We also say $\psi $ is less singular than $\varphi $ and write $\psi \succeq \varphi $.

In case $\varphi \preceq \psi $ and $\psi \preceq \varphi $, we say $\varphi $ and $\psi $ have the same singularity type. We write $\varphi \sim \psi $ in this case.

From Singularities in Hermitian pluripotential theory · Definition 1.12.1
Read this source version and its proof notes

Definition 1.12.1. Let $u,v$ be quasi-plurisubharmonic functions on $X$. We write $u\preceq v$ if there is a constant $C\in \mathbb R$ such that $u\leq v+C$ on $X$, and $u\sim v$ if both $u\preceq v$ and $v\preceq u$; in the latter case $u$ and $v$ have the same singularity type. When this has to be distinguished from the multiplier-ideal type introduced below, we speak of the ordinary singularity type, or simply the ordinary type.
