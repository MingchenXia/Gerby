Lemma 9.4.456B45ADBA326

Lemma 9.4.4. Let $K,L\subset D$ be compact sets with $K\subset \operatorname{Int}L$, and let $f$ be a real Borel function which is defined and quasi-continuous on a neighborhood of $L$. Then, for every $\delta >0$,

\[ \operatorname {Cap}_ D^*(K\cap \{ |f|>\delta \} ) \le \operatorname {Cap}_ D(L\cap \{ |f|>\delta /2\} ). \]

Proof. Let $\eta >0$. By quasi-continuity, applied to the compact set $L$, there is an open set $G\subset D$ with $\operatorname {Cap}_ D(G)<\eta $ such that $f$ is continuous on $L\setminus G$; let $g$ be a continuous extension of $f|_{L\setminus G}$ to $\mathbb {C}^ n$ (lemma 9.4.3); here $f|_{L\setminus G}$ is bounded, being continuous on a compact set. The open set $G\cup (\operatorname{Int}L\cap \{ |g|>\delta /2\} )$ contains $K\cap \{ |f|>\delta \} $, since $K\subset \operatorname{Int}L$ and $g=f$ on $K\setminus G$. Its part outside $G$ is a Borel set contained in $L\cap \{ |f|>\delta /2\} $, because $g=f$ on $L\setminus G$. By monotonicity and subadditivity,

\[ \operatorname {Cap}_ D^*(K\cap \{ |f|>\delta \} )\le \eta +\operatorname {Cap}_ D(L\cap \{ |f|>\delta /2\} ). \]

Let $\eta \downarrow 0$. $\square$
