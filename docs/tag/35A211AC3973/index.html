Example 7.4.5

From Singularities in global pluripotential theory · Example 7.4.5

Example 7.4.5. If $X$ is a smooth projective toric variety and $\theta $ is invariant under the action of the compact torus, then any $\varphi \in \mathrm{PSH}_{\mathrm{tor}}(X,\theta )$ is $\mathcal{I}$-good.

Proof. Thanks to 7.1.4, we may assume that $\theta \in c_1(L)$ for some toric invariant ample line bundle $L$. In this case, the result follows from theorem 7.1.1, theorem 7.4.2 and theorem 5.2.14. $\square$
