Lemma 21.1.12B103C3B777A

Lemma 21.1.1. For every finite-dimensional vector subspace $V\subset H^0(X,L^ m)$,

\[ \# \{ \nu (s):0\neq s\in V\} =\dim V. \]

Proof. Sections with distinct valuations are linearly independent: in a nontrivial finite linear combination of them, the smallest valuation occurs in exactly one summand and cannot cancel. Hence there are at most $\dim V$ values.

For the reverse inequality, we argue by induction on $\dim V$, the case $\dim V=0$ being immediate. The nonempty set of values has a smallest element $a$ in the lexicographic order. The Taylor coefficient of the monomial $z^ a$ is a nonzero linear functional on $V$. Its kernel has codimension one, and every nonzero element of the kernel has valuation strictly larger than $a$. By the induction hypothesis the kernel contributes $\dim V-1$ distinct values, all different from $a$. $\square$
