Proposition 15.7.27DD0741AE5AA

Proposition 15.7.2. For these model references,

\[ \Delta (\varphi ,\psi ) =\sup _{\operatorname {Ent}_{\mathrm{d}V}(\nu )<\infty } |H_\varphi (\nu )-H_\psi (\nu )|, \]

where the supremum is over probability measures of finite entropy. The same value is obtained if (15.28) uses all bounded measurable $G$, and it does not depend on the smooth positive reference volume.

Proof. By corollary 15.6.3, both duals are finite exactly on the probability measures of finite entropy; rescaling the reference volume to have mass one does not affect finiteness. A uniform bound for $|B_\varphi -B_\psi |$ passes to the defining suprema, so the supremum in the statement is at most $\Delta (\varphi ,\psi )$. Conversely, denote that supremum by $D$. If $\nu \in \mathcal A_\psi (G)$, then $\nu $ has finite entropy, and the dual minimum formula gives

\[ B_\varphi (G) \leq H_\varphi (\nu )-\int _ XG\, \mathrm{d}\nu \leq B_\psi (G)+D. \]

Interchanging the references gives the opposite inequality, so $\Delta (\varphi ,\psi )\leq D$.

For bounded measurable $G$, take continuous approximations with the same uniform bound converging in $L^1(\mathrm{d}V)$; the continuity theorem theorem 15.1.3, applied to each of the two references, extends the scalar bound to $G$. Finally, a change of volume $\mathrm{d}V'=\mathrm{e}^ a\mathrm{d}V$ replaces each $B(G)$ by $B(G+a)$, and translation by $a\in C(X)$ is a bijection of the space of tests, so the supremum is unchanged. $\square$
