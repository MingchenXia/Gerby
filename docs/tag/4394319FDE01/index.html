Theorem 7.2.24394319FDE01

Theorem 7.2.2. For $p>0$, the damped measures $\nu _{p,u}=\mathrm{e}^{pu}\mu _ u$ satisfy

\[ \nu _{p,u}(X)\leq C_\omega (1+p^{-1})^{r_ n}, \qquad \nu _{p,u}(E)\leq \max (1,n/p)^ n\operatorname {Cap}_\omega (E) \]

for every Borel set $E\subset X$, uniformly over all nonpositive $u\in \mathrm{PSH}(X,\omega )$.

Proof. Take $a=p/n$ in proposition 7.2.1. Since $F_{p/n}(u)$ takes values in $[0,n/p]$, proposition 7.1.1 with $A=n/p$ gives the total mass bound, after enlarging $C_\omega $. For the capacity bound put $B=\max (1,n/p)$ and $v=F_{p/n}(u)$. Then $v/B$ is a test function for the capacity, and

\[ B\bigl (\omega +\mathrm{dd}^{\mathrm{c}}(v/B)\bigr ) =(\omega +\mathrm{dd}^{\mathrm{c}}v)+(B-1)\omega \geq \omega +\mathrm{dd}^{\mathrm{c}}v. \]

Consequently $\nu _{p,u}\leq \mathrm{MA}_\omega (v)\leq B^ n\mathrm{MA}_\omega (v/B)$, which gives the second bound. The measures $\nu _{p,u}$ do not charge pluripolar sets, because $\mu _ u$ does not. $\square$
