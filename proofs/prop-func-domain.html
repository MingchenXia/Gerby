Proof. For positive source and target dimensions, apply the holomorphic pullback theorem. Its conclusion is precisely that $\varphi\circ f$ is plurisubharmonic or identically $-\infty$ on each connected component. Here the source is connected, so there is just one alternative to consider. They are disjoint because the definition of plurisubharmonicity excludes the function identically $-\infty$.

If the source has dimension zero, it is a point: the pullback is either a finite number or $-\infty$. If the target has dimension zero, $\varphi$ is finite and constant, and so is its pullback. Thus these cases satisfy the same assertion.
